    Seguridad

    Reglas de firewall

    Pulsa una regla para ver su justificación.

    Aísla dispositivos no confiables. Si alguno se ve comprometido, no puede alcanzar el servidor ni los clientes.
    Solo los servicios que uses desde los clientes. Nada de "todo permitido" entre zonas.
    Ninguna conexión entrante por defecto. El acceso remoto se hará con VPN WireGuard, no con port forwarding.
    Solo la VLAN de gestión puede acceder a SSH y a la interfaz del USG y del switch.

    Switch y gateway

    Fragmentos de referencia. Los valores reales se sanean antes de publicarse.

vlan 10,20,30,40
interface gi1
 switchport mode trunk
 switchport trunk native vlan 10
 switchport trunk allowed vlan add 10,20,30,40
exit
interface gi2
 switchport mode access
 switchport access vlan 30
exit
end

    Controlador UniFi Network
 → Redes: VLAN 10 (Gestión, nativa) · 20 (Clientes) · 30 (Homelab) · 40 (IoT)
 → WAN: DHCP / PPPoE según operadora
 → Firewall: IoT → RFC1918 = BLOCK
             Clientes → Homelab = ALLOW (puertos concretos)
             WAN → LAN = BLOCK
 → Acceso remoto: WireGuard
